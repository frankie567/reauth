# Reauth brand

The signature orange is **#D66B36** in every context, including light and dark mode.
Use warm ivory **#F3EEDF** or charcoal **#20231F** as the background.

- `logomark.svg`: orange brick, transparent background.
- `logotype.svg`: ink lettering for light backgrounds.
- `logotype-dark.svg`: cream lettering for dark backgrounds.
- `logo.svg` and `logo-dark.svg`: combined brick and lettering.

Lettering is outlined from Space Grotesk SemiBold (600), with no external font dependency.
The source font is [Space Grotesk](https://github.com/floriankarsten/space-grotesk), licensed under the SIL Open Font License.

Website typography uses Space Grotesk Regular (400) and SemiBold (600).
IBM Plex Mono is reserved for code. Labels use sentence case.
The website favicon at `docs/images/favicon.svg` is a copy of `logomark.svg`.
